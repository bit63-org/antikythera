# Design Document — build-and-ci

## Overview

```
vcpkg.json + vcpkg-configuration.json + vcpkg-overlays/
        │  vcpkg install (manifest mode)          ┌── L1: actions/cache of vcpkg_installed/
        ▼                                          └── L2: OCI vcpkg binary cache (optional)
<source>/vcpkg_installed/<triplet>
        │  cmake/Vcpkg.cmake → CMAKE_PREFIX_PATH, PKG_CONFIG_PATH
        ▼
CMakeLists.txt ── cmake/{Warnings,Hardening,Sanitizers,CompilerLauncher}.cmake
        │                                          └── sccache → OCI L2 (optional)
        ▼
src/  tests/ (ctest, Boost.Test)  fuzz/ (libFuzzer, Clang)
```

## CMake

- Top-level `CMakeLists.txt` sets C++23, turns off module scanning and
  enforces the compiler floor before anything else is configured.
- `cmake/Vcpkg.cmake` picks the triplet (`x64-linux` or `arm64-linux`),
  sets `_VCPKG_INSTALLED_DIR` and `VCPKG_TARGET_TRIPLET` for port config
  scripts that read them, and prepends the installed tree to
  `CMAKE_PREFIX_PATH` and `PKG_CONFIG_PATH`. With no installed tree it
  falls back to system packages.
- `cmake/Warnings.cmake` and `cmake/Hardening.cmake` define the
  `ak::warnings` and `ak::hardening` interface targets.
  `cmake/Sanitizers.cmake` applies ASan + UBSan globally under
  `AK_SANITIZE`, and hardening drops `_FORTIFY_SOURCE` there.
- `cmake/CompilerLauncher.cmake` keeps separate cache entries for ccache and
  sccache so a later change of launcher is honoured, clears the launcher
  when set to `none`, and strips PCH timestamps under Clang so cached
  objects stay reusable.

## Dependencies

| Dependency | Source | Gate |
|---|---|---|
| Boost.Test ≥ 1.89 | baseline | `AK_TESTS` |
| OpenSSL ≥ 3.6.5 | `microsoft/vcpkg` git registry, scoped to `openssl` | required |
| libvfio-user v0.8 | overlay port `vcpkg-overlays/libvfio-user` | `vfio-user` feature, `AK_VFIO_USER` |

`AK_VFIO_USER` is `AUTO`, `ON` or `OFF`. Under `AUTO` a missing library
skips the device servers with a warning, unless the `vfio-user` feature is
installed, in which case configure fails rather than silently dropping
`ak-testdev`. The overlay port generates the `libvfio-user.pc` upstream
does not install; a `find_path`/`find_library` fallback finds a plain
`meson install`.

## Lint

- `.clang-format` is generated by clang-format 22.1.5 (PyPI), the version
  kythira pins.
- `.clang-tidy` is kythira's, unchanged, run with clang-tidy 19 against
  `compile_commands.json` (exported by default).

## Caching

Mirrors kythira's `doc/ci_build_cache.md` and its `oci-build-cache`
composite action:

- **L1**: `actions/cache` keyed on the triplet, compiler and a hash of
  `vcpkg.json`, `vcpkg-configuration.json` and `vcpkg-overlays/**`.
- **L2**: vcpkg binary cache and sccache in kythira's OCI bucket, under
  antikythera's own three credentials (read-only, create-only for pull
  requests, read-write for main). vcpkg archives are content-addressed and
  sccache keys cover the full compile, so the two repositories reuse
  identical results and cannot collide.
- `scripts/oci-build-cache/start-sccache.sh` decides per job whether sccache
  is usable by round-tripping a real compile, since neither
  `--start-server` nor `--show-stats` distinguishes a dead backend. It
  writes `launcher=sccache` only on success; otherwise the job configures
  with `AK_COMPILER_LAUNCHER=none` and builds from source.

L2 uses real cloud resources and is enabled only with Clark's go.

## CI

GitHub Actions, one workflow, jobs:

| Job | Compiler | Steps |
|---|---|---|
| `gcc` | GCC 14 | vcpkg install (L1), configure, build, ctest |
| `clang` | Clang 19 | same |
| `sanitize` | Clang 19 | `AK_SANITIZE=ON`, build, ctest |
| `fuzz` | Clang 19 | `AK_FUZZ=ON`, build, short smoke run of each target |
| `lint` | — | clang-format 22.1.5 `--dry-run --Werror`, clang-tidy 19, shellcheck |
| `arm64` | GCC 14 cross | configure and build for `arm64-linux` |

All jobs are required checks on main. Concurrency groups cancel superseded
runs on the same branch.

## Cloud development environment

`.claude/hooks/session-start.sh`, registered as a SessionStart hook in
`.claude/settings.json`, installs `gcc-14`, `g++-14`, `clang-19`,
`clang-tidy-19`, `libclang-rt-19-dev`, `cmake`, `ninja-build`,
`libboost-test-dev`, `libssl-dev` and `shellcheck` from the Ubuntu archive,
and clang-format 22.1.5 from PyPI. A repo hook rather than an environment
setup script, because it travels with the repository. Threads configure
against system packages without vcpkg.
